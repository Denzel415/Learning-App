# Learning App

A personal learning app built on recall, spacing and mixed practice. The first course is SQL for GTM work.

Open `index.html` in a browser to use it. Run `node tools/test.js` to check the scheduler and course content.
To restyle it, start with the tokens at the top of `styles.css`. To add or edit questions, see `courses/sql-1.js`.

`CLAUDE.md` has the full picture of how it is put together.
